# B站评论区一键@好友（油猴脚本）

> **当前版本：v0.10.0** — 设置面板改版：换行自动保存 UID、右侧实时显示 UID→昵称 解析结果（成功/失败标色）。

在 B 站视频评论区一键@群友。设置界面维护 UID 列表，脚本自动解析为**当前昵称**（成员改名自动跟上），右下角点一下把 `@昵称` 插入评论框，由你手动点发送。超长自动分批。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）
2. 打开 `bili-at-all.user.js`，Tampermonkey 会弹出安装页 → 安装

## 使用

1. 打开任意 B 站视频页，点右下角 **⚙** 打开设置
2. 把好友 UID **每行一个**粘贴进左侧输入框——**每换一行自动保存**，也可点「保存」手动保存
3. 右侧实时显示 `UID → 昵称`：成功绿色、失败红色、有旧缓存但更新失败橙色；点「测试解析昵称」拉取最新昵称
4. 回到评论区，点右下角 **@全部** → 名单插入评论框 → 自己点发送
5. 超过单条评论上限时会自动分批：发送后按钮变成「下一批 n/N」，再点一下插入下一批

## 存储与解析

- UID 列表存于 `GM_setValue('biliAtAll_uids')`
- 昵称缓存存于 `GM_setValue('biliAtAll_cache')`，有效期 24 小时；改名后一天内自动刷新，也可在设置里「清空昵称缓存」
- 昵称接口：`https://api.bilibili.com/x/web-interface/card?mid=UID&photo=false`（免登录、无需 wbi，并发 10）

## 插入机制（三级兜底 + 校验）

1. **模拟纯文本粘贴**（`ClipboardEvent` + `DataTransfer`）：B 站编辑器会把粘贴的 `@昵称 ` 转成真实可点击的提及节点（已由用户实测确认）
2. 兜底 `document.execCommand('insertText')`
3. 再兜底直接 DOM 插入文本节点 + 触发 `input` 事件

插入后脚本会尝试数出编辑器里真实提及节点数，与预期人数比对，不一致时明确提示，绝不静默装成功。

## 技术说明

- 评论框查找：递归穿透 shadow DOM 扫描 `contenteditable`，优先选有实际布局的（即当前可见评论框）
- 纯逻辑部分可单测：`npm install && npm test`（node ≥ 18）
