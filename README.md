# B站评论一键@好友（油猴脚本）

> 版本 v0.10.0

在 B 站视频评论区一键 @ 群友：提前维护一份好友 UID 列表，脚本自动解析成他们**当前的昵称**（朋友改名也能跟上），右下角点一下就把 @ 名单插入评论框，你自己检查后发送。

## 安装

方式一：一键安装
1. 浏览器安装油猴扩展（[Tampermonkey](https://www.tampermonkey.net/)）
2. 打开 `bili-at-all.user.js`，油猴会自动弹出安装页 → 安装

方式二：手动添加
1. 浏览器安装油猴扩展（[Tampermonkey](https://www.tampermonkey.net/)）
2. 打开 `bili-at-all.user.js`，全选并复制全部代码
3. 点浏览器工具栏的油猴图标 → 「添加新脚本」（或「管理面板」→「+」）
4. 清空编辑器默认内容 → 粘贴代码 → 保存（Ctrl+S）
5. 打开任意 B 站视频页，右下角出现「@全部」按钮即安装成功

## 使用

1. 打开任意 B 站视频页，点右下角 **⚙** 打开设置
2. 把好友 UID 每行一个粘贴进去——**每换一行自动保存**（也有手动保存按钮）
3. 右侧会显示每个 UID 对应的昵称：绿色=成功，红色=失败，橙色=用的是旧缓存；点「测试解析昵称」可立即拉取最新
4. 回到评论区，点右下角 **@全部** → 名单插入评论框 → 你自己点发送

## 常见问题

- **朋友改昵称了？** 昵称缓存 24 小时自动刷新；想立刻更新就在设置里「清空昵称缓存」再 @ 一次
- **人太多 @ 不下？** B站单条评论最多 @10 人，脚本会自动分批（每批 10 人），发送后按钮变成「下一批 n/N」，再点一下插入下一批
- **点 @全部 没反应？** 先点击评论区输入框（让它展开），再点按钮
- **换了浏览器？** 数据存在油猴存储里，换设备需要重新设置 UID
